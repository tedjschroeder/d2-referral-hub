## 📁 How to File Claims

### Step 1: Verify Eligibility
- Read settlement requirements carefully
- Gather proof of purchase (receipts, account statements, etc.)
- Check claim deadline (usually 60-90 days from settlement approval)

### Step 2: Prepare Documents
- Screenshots of account/purchase
- Dates of purchase/subscription
- Proof of damages (if applicable)
- ID verification

### Step 3: File Online
- Most settlements have online claim forms
- Some require mailed forms
- Keep submission confirmation

### Step 4: Track Status
- Save all correspondence
- Note case number and tracking ID
- Check status periodically (can take 6-18 months)

## 🚨 Important Warnings

1. **Deadline discipline:** Missing deadlines = no payout
2. **Scams exist:** Only file through official settlement websites
3. **Third-party claims:** Don't use middlemen who take % cuts
4. **Proof required:** Have documentation ready before filing
5. **Taxes:** Settlement payouts may be taxable (track for tax return)
